# Data layout

The seven original CSV files remain in the legacy `original analysis` folder and are never copied into Git:

- `users.csv`
- `products.csv`
- `orders.csv`
- `order_items.csv`
- `events.csv`
- `inventory_events.csv`
- `distribution_centers.csv`

Sessions are generated from `events.csv`; no separate session source is required.

Generated by `python src/run_all.py --source-csv-dir "<path>" --rebuild`:

- `data/processed/power_bi/csv/`: widest compatibility for Power BI imports.
- `data/processed/power_bi/parquet/`: faster and smaller import option.
- `data/processed/analysis/`: compact analytical marts.
- `data/processed/advanced/`: clustering, prediction, association-rule, testing, and experiment-design outputs.
- `outputs/qa/`: data-quality and reconciliation evidence.

All generated data is intentionally ignored by Git. Do not edit generated files manually; change SQL or Python and rebuild.
